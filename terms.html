利用規約

最終更新日：2026年9月13日

この利用規約は、TASK GUILD（以下「本アプリ」）の提供条件および利用者と当方との権利義務関係を定めるものです。本アプリをご利用いただく前に、必ずお読みください。

第1条（適用）

本規約は、利用者と当方との間の本アプリの利用に関わる一切の関係に適用されます。本アプリをダウンロードまたは利用した時点で、本規約に同意したものとみなします。

第2条（利用登録）

  1. 利用者は、メールアドレスとパスワードを登録することで本アプリを利用できます。
  2. 登録した情報に変更が生じた場合、速やかに更新してください。
  3. 当方は、次のいずれかに該当すると判断した場合、登録を承認しないことがあります。
    • 虚偽の事項を届け出た場合
    • 過去に本規約に違反したことがある場合
    • その他、当方が登録を適当でないと判断した場合

第3条（アカウントの管理）

  1. 利用者は、自己の責任においてアカウント情報を管理してください。
  2. アカウント情報を第三者に譲渡・貸与することはできません。
  3. アカウント情報が第三者に使用されたことによる損害について、当方は責任を負いません。

第4条（会社およびメンバー）

  1. 利用者は、本アプリ内で「会社」を作成し、招待コードを共有することで他の利用者を参加させることができます。
  2. 会社の管理者は、メンバーの権限や利用できる機能を設定できます。
  3. 招待コードの管理は、会社の管理者の責任において行ってください。第三者に漏洩した場合、意図しない参加が生じる可能性があります。

第5条（無料でご利用いただける範囲）

  1. 本アプリは、1つの会社につきメンバー3名までは無料でご利用いただけます。
  2. 無料の範囲では、本アプリのすべての機能をご利用いただけます。
  3. 4名以上のメンバーで利用する場合、次条に定める追加機能の購入が必要です。

第6条（追加機能の購入）

  1. 会社の管理者は、App Store を通じて追加機能を購入することで、メンバー数の上限を解除できます。
  2. 購入は買い切りであり、月額または年額の継続課金ではありません。
  3. 購入した会社に所属するメンバーは、追加の支払いなく本アプリをご利用いただけます。
  4. 購入は購入者の Apple ID に紐づきます。同じ Apple ID をお使いの端末であれば、「購入を復元」から再度有効にできます。
  5. 購入した管理者がアカウントを削除した場合も、その会社の購入状態は維持されます。
  6. 販売価格および購入手続きは、App Store の定めに従います。

第7条（返金）

  1. 購入代金の返金は、Apple の定める手続きによります。当方は返金の可否を判断する立場になく、直接の返金は行いません。
  2. 返金をご希望の場合は、Apple のサポートページより申請してください。
  3. 本アプリの提供を終了する場合の取り扱いは、第14条に定めます。

第8条（禁止事項）

利用者は、本アプリの利用にあたり、次の行為をしてはなりません。

  • 法令または公序良俗に違反する行為
  • 犯罪行為に関連する行為
  • 本アプリの運営を妨害する行為
  • 他の利用者の情報を不正に収集または蓄積する行為
  • 他の利用者になりすます行為
  • 本アプリのサーバーやネットワークに過度な負荷をかける行為
  • 本アプリを逆コンパイル、逆アセンブル、その他リバースエンジニアリングする行為
  • 購入手続きを経ずに、不正な方法で追加機能を利用する行為
  • その他、当方が不適切と判断する行為

また、掲示板、トーク、コメントその他の投稿機能において、次の各号に該当する内容を投稿してはなりません。

  • 他の利用者に対する誹謗中傷、侮辱、脅迫、嫌がらせにあたる内容
  • 差別的な表現、わいせつな表現、暴力的な表現を含む内容
  • 第三者の著作権、商標権その他の権利を侵害する内容
  • 本人の同意なく第三者の個人情報を記載した内容
  • 業務と関係のない宣伝、勧誘、その他のスパム行為にあたる内容
  • 法令または公序良俗に反する内容

第9条（不適切なコンテンツへの対応）

当方は、前条に定める不適切な投稿を一切許容しません。

  1. 本アプリには、利用者が不適切な投稿を通報する機能を備えています。掲示板の依頼、トークのメッセージ、依頼へのコメントを長押しすることで通報できます。
  2. 本アプリには、特定の利用者をブロックする機能を備えています。ブロックした利用者の投稿およびメッセージは、以後、利用者の画面に表示されなくなります。
  3. 通報を受けた場合、当方または会社の管理者は、24時間以内に内容を確認し、必要に応じて当該投稿の削除、または投稿した利用者の利用停止を行います。
  4. 会社の管理者は、不適切な投稿を行った利用者を無効化し、その会社のコンテンツへのアクセス権を取り消すことができます。
  5. 繰り返し違反した利用者、および悪質と判断される利用者については、事前の通知なく本アプリの利用をお断りする場合があります。
  6. 不適切な投稿に関するお問い合わせは、philia.neo.aag@gmail.com までご連絡ください。

第10条（本アプリの提供の停止等）

  1. 当方は、次のいずれかに該当する場合、事前の通知なく本アプリの全部または一部の提供を一時的に停止または中断することがあります。
    • システムの保守点検または更新を行う場合
    • 地震、落雷、火災、停電、天災などにより提供が困難となった場合
    • コンピュータまたは通信回線が事故により停止した場合
    • その他、提供が困難と判断した場合
  2. 本条の停止または中断は一時的なものを指し、恒久的な提供終了については第14条に定めます。

第11条（利用制限および登録抹消）

当方は、利用者が本規約に違反した場合、事前の通知なく、本アプリの利用を制限し、または登録を抹消することがあります。この場合、購入済みの追加機能についても利用できなくなりますが、返金には応じかねます。

第12条（退会）

利用者は、本アプリ内の設定画面から、いつでもアカウントを削除できます。削除される情報と残る情報については、削除画面に表示される内容をご確認ください。

第13条（保証の否認および免責）

  1. 当方は、本アプリが利用者の特定の目的に適合すること、期待する機能を有することを保証しません。
  2. 当方は、本アプリに起因して利用者に生じた損害について、当方の故意または重過失による場合を除き、責任を負いません。
  3. 前項にかかわらず、当方が責任を負う場合、その賠償額は利用者が当方に支払った金額を上限とします。
  4. 利用者が本アプリに登録したデータの消失や毀損について、当方の故意または重過失による場合を除き、責任を負いません。重要なデータは利用者ご自身で別途保管してください。
  5. 利用者と他の利用者との間で生じた紛争について、当方は関与せず、責任を負いません。

第14条（サービスの終了）

本アプリはインターネット上のサーバーを利用しており、提供を終了した場合はご利用いただけなくなります。この点について、次のとおり定めます。

  1. 当方は、本アプリの提供を終了する場合、終了日の 3か月以上前 に、本アプリ内および本サイトにて告知します。
  2. 利用者は、告知の期間中に、必要なデータのご確認および保存をお願いします。
  3. 購入から1年以内に本アプリの提供を終了した場合、購入者は Apple の定める手続きにより返金を申請できる場合があります。当方は、その申請に必要な情報の提供に協力します。
  4. やむを得ない事由により事前の告知が困難な場合であっても、当方は可能な限り速やかに利用者へ通知するよう努めます。

第15条（サービス内容の変更）

当方は、本アプリの機能を追加、変更、または一部廃止することがあります。追加機能として提供している内容を大きく損なう変更を行う場合は、事前に告知します。

第16条（利用規約の変更）

  1. 当方は、必要と判断した場合、本規約を変更することがあります。
  2. 利用者にとって重要な変更を行う場合、変更内容と効力発生日を、効力発生日の相当期間前までに本アプリ内または本サイトにて告知します。
  3. 変更後の規約は、効力発生日から適用されます。

第17条（個人情報の取扱い）

本アプリの利用によって取得した個人情報については、別途定めるプライバシーポリシーに従い適切に取り扱います。

第18条（通知または連絡）

利用者と当方との間の通知または連絡は、本アプリ内の表示、または本サイトへの掲載により行います。

第19条（権利義務の譲渡の禁止）

利用者は、当方の書面による事前の承諾なく、本規約上の地位または権利義務を第三者に譲渡または担保に供することはできません。

第20条（準拠法・裁判管轄）

  1. 本規約の解釈にあたっては、日本法を準拠法とします。
  2. 本アプリに関して紛争が生じた場合、当方の所在地を管轄する裁判所を第一審の専属的合意管轄とします。

本規約に関するお問い合わせは、サポートページよりご連絡ください。
