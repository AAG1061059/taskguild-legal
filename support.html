ご利用料金について

無料で使える範囲を教えてください

1つの会社につきメンバー3名までは、すべての機能を無料でご利用いただけます。掲示板、タスク、トーク、シフト管理、権限設定など、機能の制限はありません。

4人目を招待できません

無料でご利用いただけるのは3名までです。4名以上でお使いになる場合は、追加機能のご購入が必要です。その他 → アカウント から購入いただけます。

料金はいくらですか

5,000円（税込）の買い切りです。月額・年額の継続課金は発生しません。一度ご購入いただければ、追加のお支払いなくお使いいただけます。

メンバー全員が購入する必要がありますか

いいえ。会社の管理者が1回購入すれば、その会社に所属するすべてのメンバーが追加の支払いなくご利用いただけます。招待された方は、購入手続きは不要です。

機種変更したら使えなくなりました

その他 → アカウント → 「購入を復元」をお試しください。ご購入時と同じ Apple ID でサインインしている必要があります。

返金してもらえますか

当方からの返金は承っておりません。Apple のサポートページより、返金をお申し込みください。ご購入から一定期間内であれば、Apple の判断により返金される場合があります。

購入した管理者が退職しました

購入した方がアカウントを削除しても、その会社の購入状態は維持されます。引き続きご利用いただけます。

よくある質問

会社に参加できません

招待コードは英数字8文字です。大文字と小文字は区別されませんが、余分な空白が入っていないかご確認ください。コードが分からない場合は、会社の管理者にお尋ねください。

招待コードはどこで確認できますか

管理者の方は、その他 → アカウント の画面に表示されています。コピーボタンから他の方に共有できます。

タブが少ないメンバーがいます

雇用区分ごとに、使える機能を制限できる仕組みがあります。管理者の方は、その他 → 雇用区分と権限 から設定を確認・変更できます。

依頼が掲示板に出てきません

依頼には対象部署を設定できます。別の部署あての依頼は表示されません。ただし、ご自身が出した依頼、指名された依頼、受けた依頼は、部署に関係なく表示されます。

辞めたメンバーを消したいです

管理者の方は、その他 → メンバー → 対象の方 → 「このメンバーを無効にする」から操作できます。過去の依頼やシフトの記録は残り、選択肢からは表示されなくなります。あとから復帰させることもできます。

なお、無効にした方は無料枠の人数には数えられません。

リマインドの通知が届きません

端末の「設定」アプリ → TASK DAX → 通知 から、通知が許可されているかご確認ください。また、リマインドは期限を日時で指定した依頼にのみ設定できます。

パスワードを忘れました

現在、アプリ内でのパスワード再設定に対応していません。お問い合わせよりご連絡ください。

アカウントを削除したいです

その他 → アカウント → 「アカウントを削除」からご自身で削除できます。削除されるもの・残るものが画面に表示されますので、ご確認のうえ操作してください。

会社に他のメンバーがいて、管理者がご自身だけの場合は、先に別の方を管理者に変更する必要があります。

写真を添付できますか

現在、写真やファイルの送信には対応していません。
